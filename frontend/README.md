# Nextly frontend

Next.js app: the marketing site and the authenticated calendar at `/app`. See the [root README](../README.md) for what this project does, the stack, and how to run it locally.

## Frontend-specific commands

```bash
npm run dev        # dev server
npm run build      # production build
npm run lint        # eslint
npm run test:unit    # vitest
npm run test:e2e     # playwright (needs the backend running, see root README)
```
