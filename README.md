# Nextly

An adaptive scheduler that plans your week around fixed commitments and fits flexible tasks into the open space around them.

## Structure

- [`frontend/`](frontend) — Next.js app (landing page + the logged-in calendar at `/app`)
- `backend/` — Python/FastAPI constraint-solver service (not yet built)

## Getting started

```bash
cd frontend
npm install
npm run dev
```

See [`frontend/README.md`](frontend/README.md) for frontend-specific details.
